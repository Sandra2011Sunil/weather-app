# Weather App

A responsive weather application built using HTML, CSS, and JavaScript.
Fetches real-time weather data from the OpenWeatherMap API.

## Live Demo
Open index.html in any browser after adding your API key

## Features
- Search weather by any city name
- Displays real-time temperature in Celsius
- Shows weather condition with emoji icons
- Displays humidity, wind speed, and feels like temperature
- Error handling for invalid city names
- Press Enter to quickly search
- Responsive glassmorphism dark UI

## Tech Stack
- HTML5
- CSS3 (Glassmorphism design)
- JavaScript (ES6+)
- OpenWeatherMap API

## Project Structure
weather-app/
│
├── index.html   → App structure
├── style.css    → Styling and layout
└── script.js    → API calls and app logic

## How to Run
1. Clone the repository
2. Get a free API key from openweathermap.org
3. Open script.js and replace YOUR_API_KEY_HERE with your key
4. Open index.html in your browser
5. Search any city name!
